\# Data Directory



This directory contains:

\- `benchmark\_sample\_50.json`: A strictly balanced 50-pair sample for format verification.

\- `labels\_380.json`: The manual labels for the full 380-pair replication pool.

\- `annotation\_guideline.pdf`: The annotation rules.

\- `benchmark\_format.md`: Format description.



\*\*Note:\*\* Due to the large size of the raw mining pool, the full dataset is not provided during the review phase. The full benchmark will be publicly released upon paper acceptance.
