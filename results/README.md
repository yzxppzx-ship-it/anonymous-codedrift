# Results Directory

This directory contains the raw numerical data corresponding to the tables and figures in the paper. Reviewers can verify the claims by inspecting these files directly.

- `table2_auc_scores.json`: AUC scores for all baselines and our models on the balanced n=200 benchmark (Table 2).
- `table3_significance_tests.json`: Bootstrap and DeLong test results (p-values, 95% CI) on the n=380 pool (Table 3).
- `label_budget_means_stds.json`: Mean and standard deviation of probe performance across different label budgets, used to plot Figure 4.
- `S1_pilots.json`: Pilot experimental results for loss ablation, beta sensitivity, and negative sampling (Supplementary Material S1).
